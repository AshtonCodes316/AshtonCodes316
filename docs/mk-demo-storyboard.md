## Production checklist

1. Record a screen capture using **sanitized sample data** and a disposable environment.
2. Show actual terminal output only where it matches a retained test log; do not simulate a real terminal and label it live.
3. Label diagram shots **architecture illustration** and test shots **local test evidence**.
4. Exclude API keys, credentials, personal files, internal paths, and private repository code.
5. Confirm that no visual implies 24/7 autonomy, production deployment, or an activated paid provider.
6. Obtain Founder approval before publishing the finished video.
