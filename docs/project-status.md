## Reading the labels

- **Concept / documentation reviewed:** A use case or design is documented; implementation has not been established by public evidence.
- **Documented structural checkpoints:** Architecture and milestone descriptions exist; runtime verification may be pending.
- **Targeted local tests:** Specific tests ran in a particular environment. They do not imply that all tests pass or that the software is production-ready.
- **Standalone example:** A separate, small public example illustrates a principle; it is not the private product runtime.

## What this dashboard does not claim

No project listed here is represented as a verified production service, an independently audited security system, or a product with paying customers. The private repositories are not made public by these summaries.
