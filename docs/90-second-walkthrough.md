## Recording checklist

- Record the actual published pages; do not replace them with generated screenshots.
- Rehearse the Control Room rejection path before recording.
- Capture desktop at readable resolution; enable captions if editing.
- Don't claim real AI calls, customer deployments, authenticated approval, or independently certified security.
- Verify the recording's links, narration, captions, and duration before publishing.
- Keep personal information, private MK source, and credentials off screen.

## Acceptance

A reviewer can see a problem, an interactive decision, a negative outcome, evidence, and a clear scope limitation within 90 seconds. **A written script is not a finished video.**
