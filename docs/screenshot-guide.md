# Capturing real screenshots for the portfolio

**No screenshots have been captured or published as part of this update.** The portfolio homepage uses clearly labeled CSS illustrations, not fabricated screenshots.

Capture these **six real browser screenshots** on your computer, using fictional inputs only:

1. **Automation Lab — blocked:** Show `BLOCKED_APPROVAL` with approval off.
2. **Automation Lab — approved:** Show `DRAFT_READY_FOR_HUMAN_REVIEW` with approval on.
3. **Workflow Studio — blocked:** Show missing requirements/access/owner.
4. **Workflow Studio — ready:** Show `READY FOR REVIEW` with all checks satisfied.
5. **Implementation Dashboard — blocked:** Show outstanding milestones and blockers.
6. **Implementation Dashboard — eligible:** Show `GO_LIVE_REVIEW_ELIGIBLE` after all milestones and simulated approval.

## How to capture

- Open the relevant live demo at 100% browser zoom, with a desktop-sized window.
- Use **Windows + Shift + S** and select the application region.
- Save each image as a PNG with a clear name (e.g., `automation-lab-blocked.png`).
- Ensure the screenshot contains **no real customer names, emails, credentials, personal notifications, or private MK material**.
- Upload the six PNGs here when ready. They can then be added to the public repository and linked from the landing page with accurate captions.
