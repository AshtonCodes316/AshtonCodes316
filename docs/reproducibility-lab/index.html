Verification checklist

  1. Inspect the exact source revision before running commands.
  2. Use a disposable environment and avoid secrets or production accounts.
  3. Record the command, environment, output, and commit hash.
  4. Compare observed outcomes with test expectations; investigate discrepancies.

These commands are intended for Python standard-library tests. The public examples' READMEs are authoritative for any environment-specific instructions. A green CI badge alone does not establish security or production reliability.
