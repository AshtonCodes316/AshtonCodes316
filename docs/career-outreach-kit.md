## Application tracking fields

Track: company, role, application URL, remote eligibility, salary if posted, date verified, application date, contact, portfolio link sent, follow-up date, status, and next action. Record only actual submissions, not planned ones.

## Before sending

- Verify the listing is open, remote eligibility and experience requirements fit, and the employer is legitimate.
- Tailor the first paragraph to the actual job description; do not invent experience, outcomes, credentials, or tools.
- Include the one-page profile or a relevant project, not every link at once.
- Keep security case-study claims bounded: the latest reported acceptance tests exposed significant failures, not a production-secure authorization system.
- Obtain approval before submitting applications, sending messages, or modifying LinkedIn.
